# Isaac Sharief for President

Static GitHub Pages campaign site for Isaac Sharief and the American Vanguard party.

## Publish

Upload these files to a GitHub repository and enable GitHub Pages from the repository settings. `index.html` is the homepage.

## Before publishing

- Replace `assets/photo-required.svg` references with a real Isaac Sharief campaign photo.
- Add the real campaign email on `news.html` and `privacy.html`.
- Connect forms to a secure form service for central signup records.
- Connect `donate.html` to an approved contribution processor.

The current forms store entries in the visitor's browser so the site works without a backend.
